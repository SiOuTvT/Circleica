## 修复 next/image 图床白名单导致 Galvelica 首页崩溃
- 现象：访问 `/galvelica` 抛 `Invalid src prop (https://res.cngal.org/...) on next/image, hostname "res.cngal.org" is not configured under images`——编辑器精选(editor-pick)组件里 CnGal 封面图床未加入白名单，`next/image` 在 SSR 阶段直接整页崩。
- 根因：`next.config.ts` 的 `images.remotePatterns` 缺 Galvelica 各源图床域名。
- 修复：按 DB 实测封面域名（`SELECT host FROM coverImage`）补全白名单——实际入库 5 个域名中只有 `t.vndb.org` 已配，其余 `tucang.cngal.top`(648)/`res.cngal.org`(14)/`shared.cdn.queniuqe.com`(3)/`media.st.dl.eccdnx.com`(1) 全缺；并前瞻加 Steam/Bangumi/月幕 图床防以后踩坑。
- 验证：重启宿主 netns dev server（`nohup ... & disown` + `dangerouslyDisableSandbox`，netstat 确认 `:3000 LISTENING`）；`/galvelica` HTTP 200、首页零 `unconfigured-host` 字样；真实 `res.cngal.org`/`tucang.cngal.top` 封面经 `/_next/image` 优化端点均返回 200 image/png。
- 注意：`res.cngal.org/.../default/app.png` 是 CnGal 默认占位图，部分作品把该默认图当 cover 存了（数据质量小瑕疵，非本次范围，未处理）。
- 没碰 C 盘；临时诊断脚本已清理；记忆已补长期约定。
