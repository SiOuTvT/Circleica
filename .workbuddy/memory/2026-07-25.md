- 背景：上一轮为绕沙箱 DB 不可达，给 `prisma.ts` 加了「示例数据回退」（`prisma-mock.ts` 编了 12 部游戏+公告+评论等假内容）。用户明确反感（"假数据好难受，你可以做没内容的框啊也不要这样搞假数据"）。

## 修：SetupWizard React key 警告（"Each child in a list should have a unique key prop"）
- 现象：浏览器 console 报 key 警告，代码框指向 `setup-wizard.tsx:378`（logo 占位 div）——但那不是列表本身，是 React 就近显示的代码框。
- 根因：`src/lib/utils.ts` 的 `withLabelableId` 在 children 为数组时直接 `node.map((n)=>withLabelableId(n,id))` **未补 key**。SetupWizard 的「密码」「确认密码」两个 `Field` 的 children 由多节点组成（relative 包裹 div + 条件渲染块），`children` 成数组 → 经 `withLabelableId` 映射后丢失 key → 警告。
- 修法：import 加 `Children`；数组分支改为 `Children.map(node, (n)=>withLabelableId(n,id))`（自动补/保留 key）。`tsc` 通过，dev server 重起首页/列表/详情均 200。
