加载失败

档案数据未能成功获取，请稍后重试。

设计目的：把 Empty / NotFound / Error 三态并列展示，作为全档案页统一的状态语言；文案区分「无数据」与「无匹配」，避免用户误判；操作按钮仅在可恢复态（NotFound/Error）出现。
